# ARCHIVE 021 — WHITE BLOSSOM

یک تجربه سالگرد سینمایی، فارسی و راست‌چین برای عباس و کیانا؛ بدون فریم‌ورک و آماده انتشار روی GitHub Pages.

## جایگزینی عکس‌ها
فایل‌های خودتان را با این نام‌ها در `assets/photos/` قرار دهید (یا نام فایل‌ها را در `index.html` تغییر دهید):
- `first-meeting.jpg` — تصویر/فریم اولین دیدار (در نسخه فعلی جایگاه راهنماست)
- `cafe-terrace.jpg`
- `mehr-street.jpg`
- `garden.jpg`
- `white-blossom.jpg`

برای اولین خاطره، فایل `first-meeting.jpg` را می‌توانی به‌عنوان تصویر اصلی در محل `film-placeholder` جایگزین کنی. اگر عکس را در HTML اضافه کردی، اندازه‌اش با CSS ریسپانسیو می‌شود.

## افزودن آهنگ
آهنگ خودتان را در `assets/audio/` با نام `our-song.mp3` بگذارید. سپس دکمه «موسیقی خاموش» در بالای سایت آن را کنترل می‌کند. پخش خودکار فعال نیست؛ مرورگرها معمولاً برای پخش صدا به لمس کاربر نیاز دارند.

## افزودن ویدیوی پایانی
ویدیوی MP4 خودتان را در `assets/videos/` با نام `our-moments.mp4` بگذارید. ویدیو در بخش پایانی نمایش داده می‌شود. برای پشتیبانی بهتر، MP4 با ویدیوی H.264 و صدای AAC مناسب است.

## اجرای محلی
فایل `index.html` را باز کنید. برای تست دقیق‌تر می‌توانید از افزونه Live Server در ویرایشگر کد استفاده کنید.

## انتشار با GitHub Pages
1. یک repository جدید بسازید.
2. محتویات همین پوشه را در ریشه repository آپلود کنید؛ `index.html` باید در ریشه باشد.
3. به `Settings` → `Pages` بروید.
4. در `Build and deployment` گزینه `Deploy from a branch` را انتخاب کنید.
5. شاخه `main` و پوشه `/(root)` را انتخاب و Save کنید.
6. پس از آماده شدن، لینک سایت در همان بخش نمایش داده می‌شود.

GitHub Pages فایل‌های HTML/CSS/JS و رسانه‌های استاتیک را منتشر می‌کند. توجه کنید که سایت عمومی است و هر کسی که لینک را داشته باشد ممکن است آن را ببیند؛ اطلاعات خصوصی یا فایل‌هایی را که نمی‌خواهید عمومی شوند در repository نگذارید.

## پایان مخفی
پاسخ سؤال پایانی فقط در مرورگر همان بازدیدکننده استفاده می‌شود و به هیچ سروری ارسال یا ذخیره نمی‌شود. این یک قفل واقعی امنیتی نیست؛ صرفاً یک غافلگیری تعاملی برای تجربه هدیه است.


### فایل‌های شخصی اضافه‌شده
عکس‌ها و ویدیویی که فرستادی داخل سایت قرار گرفته‌اند. آهنگ مشترک را اگر خواستی، با نام `our-song.mp3` در `assets/audio/` قرار بده.
